# A&Z Gadgets Enterprise - landing page

Company website: https://azgadgetsenterprise.com/

This repository contains the static landing page only. WooCommerce runs separately and is not deployed by GitHub Pages.

Edit index.html for content, assets/styles.css for layout, and assets/main.js for navigation. Changes pushed to main publish through GitHub Pages.

The production page is crawlable and includes canonical metadata and a sitemap. Preserve CNAME when updating the published files. The hero is illustrative generated artwork; range photos are historical images from A&Z's public social archive, with availability confirmed directly by the shop. Self-hosted fonts include their OFL licences.
