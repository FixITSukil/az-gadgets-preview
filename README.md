# A&Z Gadgets Enterprise - landing preview

Customer design preview: https://fixitsukil.github.io/az-gadgets-preview/

This repository contains the static landing page only. The online store and checkout are a later phase.

Edit index.html for content, assets/styles.css for layout, and assets/main.js for navigation. Changes pushed to main publish through GitHub Pages.

The preview carries noindex. The hero is illustrative generated artwork; range photos are historical images from A&Z's public social archive, with availability confirmed directly by the shop. Self-hosted fonts include their OFL licences.
